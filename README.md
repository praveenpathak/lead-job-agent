- **Local URL (Is PC par):** `http://localhost:3777`

- **GitHub Repo:** `https://github.com/praveenpathak/lead-job-agent`

## 1. Roz Kaise Start Karein?
- **Local PC par:** Folder mein [start.bat](start.bat) par **double-click** karein (Desktop shortcut bana lein — 1 click mein server + browser khulega).
- **Phone / Office / Doosre PC par:** Seedha `https://lead-job-agent.onrender.com` kholein *(free Render plan par 15 min idle ke baad pehli baar khulne mein ~30–50 sec lagte hain)*.
- **Naye Updates Live Karne ke Liye:** `https://dashboard.render.com` → `lead-job-agent` → **Manual Deploy → Deploy latest commit**.

## 2. 🏪 Business Leads Tab (Client Leads Nikalna & Pitch Karna)
1. **Locations (Multi-Select):** India ke sabhi 28 States + UTs + 37+ cities, USA ke states & cities, Canada, UAE/Dubai, UK, Europe, Australia, LATAM & Africa. Search karke multiple tick karein ya **`+ Add typed`** se koi bhi chhota shehar add karein.
2. **Niches / Categories (Multi-Select):** **43 niches** (Restaurant, Jewelry, Shopping, Roofing/Construction, Real Estate, Cosmetics, Pharmacy, Solar/Home Services, IT/Software, Architecture/CAD, Graphic/Printing, etc.).
3. **Platform / Tech / Need:**
   - `WordPress + Shopify`, `Only WordPress`, `Only WooCommerce`, `Only Shopify`, `PHP`, `Laravel`, `React`, `Angular`, `Needs SEO Fix`, `Needs Redesign`, ya `All websites` (max leads ke liye!).
   - `Businesses with NO website` → jinhe nayi website bech sakte hain.
4. **Live Streaming & Stop:**
   - **`Find Leads`** dabayein — 3–5 sec mein leads row-by-row table mein aana shuru ho jayengi.
   - Kaafi leads milte hi **`⏹ Stop`** daba sakte hain (mili hui leads save rahengi).
   - **`⭐ Saved Presets`:** `USA Roofing (WP)`, `Dubai Jewelry (Shopify)` jaise 1-click presets use karein ya **`+ Save Current`** se apna preset banayein.
5. **Lead Score Badges:**
   - **🔥 Hot:** Email + Phone/WhatsApp + Website Issues (sabse pehle pitch karein!)
   - **⚡ Warm:** Good contact / platform match
   - **Clean site → Maintenance pitch:** Website already achi hai — monthly care plan pitch karein!
6. **Extra Buttons:** **`📍 Google Maps`** & **`in LinkedIn Leads`** (agar aur businesses dhoondhne hon).

## 3. ✉ Pitch Popup (Email, WhatsApp, Instagram, LinkedIn, PDF)
Kisi bhi business ke aage **`✉ Pitch`** (ya upar **`⚡ Pitch Queue`**) dabayein:
- **🎭 Pitch Tone Switcher:** `Friendly & Positive`, `USA/Dubai Corporate`, `Indian Business (Hinglish Warm)`, ya `My Custom Template`.
- **Email wale leads ke liye:** **`📧 Open in Gmail`** dabayein — To, Subject & Pitch pre-filled Gmail khulega!
- **Bina Email wale leads ke liye:**
  - **`💬 WhatsApp`** (phone number se pre-filled Short DM khulega!)
  - **`📋 Copy Short DM (300c)`** → **`📸 Instagram`** / **`📘 Facebook`** / **`in Find Owner`** par paste karein (copy hote hi green toast dikhega).
  - **`🌐 Contact Form`** → seedha website ke Contact page par paste karein.
- **Client `"Yes"` Reply Kare Tab:**
  - **`📄 Audit PDF`** → Praveen Pathak ke naam se branded Website Health Audit PDF save/print karein.
  - **`💵 Quote PDF`** → 3-package Proposal & Price Quote PDF (`$99 / ₹4,999`, `$499 / ₹24,999`, `$149/mo / ₹6,999/mo`) save/print karein.
  - **`📊 Speed Proof`** → Live Google PageSpeed Insights khol kar screenshot bhejein.
- **⚡ Pitch Queue:** **`⚡ Pitch Queue`** dabane par modal mein **`⏭ Next Lead`** button aayega — 10 minute mein 15–20 leads pitch kar sakte hain.

## 5. 💼 Remote Jobs Tab
1. **Skill Preset:** `WordPress & Shopify`, `PHP & Laravel`, `Graphic Design / UI / Figma`, `SEO & Digital Marketing`, `CAD / AutoCAD / 3D`, `CAD + Graphic Design`, `Frontend`, `All IT & Design Skills`.
2. **Region, Job Type & Work Mode:** `India`, `USA`, `Canada`, `Dubai/UAE`, `UK`, `Europe`, `Anywhere`; `Full-Time (Company)` / `Contract` / `Part-Time`; `Remote Only` ya `Remote + On-site/Hybrid`.

5. **Portal Shortcuts:** **`in LinkedIn`**, **`in Hiring Posts`**, **`Naukri`**, **`Indeed`**, **`Glassdoor`** 1-click search buttons.

## 6. 📋 My Applications, Follow-Ups & Backup
- **Auto-Save:** Jab bhi aap Gmail, WhatsApp, LinkedIn, Contact Form ya Job Apply par click karte hain, wo automatically save hota hai aur table mein **`✔ Pitched`** / **`✔ Applied`** dikhta hai.
- **⏰ 3-Day Follow-up Reminder:** 3 din baad top par yellow alert banner + har row par **`⏰ Follow-up Due`** aur **`↩ Follow-up`** button aayega.
- **💰 Deal Pipeline & Call Notes:** Har lead ke saath **Call Note** aur **Deal ($)** daalein — upar **`$X pipeline · $Y won`** aur **`📞 Call Script`** milega.
- **📊 Daily Goal Tracker:** Left sidebar mein `Today's Goal: Pitches / 10 · Job Applies / 5`.
- **Backup (Bina `.json` ke):**
  - **`📋 Copy Sync Code` / `📥 Restore Sync Code`:** Text code copy karke WhatsApp ("Message Yourself") / Google Keep / Gmail Draft mein save karein aur kisi bhi PC/phone par restore karein.
  - **`⬇ Excel / CSV`:** Google Sheets / Excel mein download karein.
  - **☁️ Google Sheets Auto-Sync:** `👤 My Profile` mein **`❓ 30-sec Setup`** follow karke Webhook URL daalein — har Pitch/Apply automatically Google Sheet mein save hoga!
