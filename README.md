# 🎯 Lead & Job Agent (WordPress / Shopify)

Zero-dependency Node.js app (Node 18+). Koi API key / paid account nahi chahiye.

## Start
```
double-click start.bat
# ya
node server.js   → http://localhost:3777
```

## 1. Business Leads tab
- Area likho (e.g. `Dubai, UAE`, `New York`, `Jaipur, India`, `London`) + niche choose karo (restaurant, jewelry, shopping, salon, hotel, gym, real estate…).
- Agent **OpenStreetMap** se us area ke real businesses nikalta hai, phir har website khol ke check karta hai:
  - Platform: **WordPress / WooCommerce / Shopify** (Wix, Squarespace bhi)
  - Theme, WP version
  - Email (homepage + contact page), phone, Instagram/Facebook/WhatsApp/LinkedIn
  - **Pitch opportunities**: no SSL, not mobile friendly, slow, outdated WP, old copyright, no SEO description, website down, Wix→WordPress migration…
- Platform = "Businesses with NO website" → jin businesses ki website hi nahi hai (new website pitch).
- ⬇ CSV se Excel/Google Sheets me export.

## 2. Check My URL List tab
Google Maps / Instagram / directories se mili koi bhi websites paste karo → platform + contacts + problems.

## 3. Remote Jobs tab
Live jobs from **Remotive, RemoteOK, Jobicy, We Work Remotely, Himalayas, Arbeitnow**.
Keywords: wordpress, shopify, woocommerce, elementor, liquid… Region: USA, Dubai/UAE, UK, Europe, Canada, Australia, India/Asia, Anywhere.
`Strong` = skill job title me hai; `Medium` = description/tags me.

## Notes
- Map data free public servers se aata hai – kabhi busy ho to 1 min baad retry karo; bade country ki jagah city use karo.
- Cold email bhejte waqt local anti-spam laws (CAN-SPAM, GDPR, UAE PDPL) follow karo; unsubscribe option do.
